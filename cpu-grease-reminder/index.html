📋 塗り替え時期の目安

グリスの種類目安備考
標準グリス（付属品・安価品）1〜2年乾燥しやすい
高性能グリス（Kryonaut 等）約1年高温環境ではポンプアウト・乾燥が早い
長寿命グリス（MX-4 / MX-6 等）2〜3年メーカー公称はさらに長いが実用上の目安
相変化シート（PTM7950 等）5年〜塗り替えほぼ不要とされる
液体金属約2年ニッケルメッキ以外の銅・アルミには使用不可

経過時間はあくまで目安です。本当のサインは温度：同じ負荷で塗布直後より +8〜10°C 上がっていたら、期限前でも塗り替えを検討してください。各デバイスの「温度ログ」に負荷時温度を記録すると、基準からの上昇を自動でチェックします。毎日高負荷（ゲーム・エンコード・ローカルLLM等）で使うPCは、目安より短めの間隔をおすすめします。

データはこのブラウザの localStorage にのみ保存されます。機種変更・ブラウザ変更の前に「書き出し」でバックアップしてください。
