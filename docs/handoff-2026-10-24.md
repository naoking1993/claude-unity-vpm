## 確認済み（Linux、2026-10-24）

- 上流 10.3.0 は無改変だと FastMCP 4 で起動できない（`MiddlewareServerSession` の ImportError）。テストスイートは通ってしまうので、起動して確かめること。
- 移植版（`10.3.0+fastmcp4.2`、独立レビューの指摘を反映済み）：上流テスト 1,550 passed（既知の環境依存 1 failed）、ライブ検証はソース 31/31・インストール済み wheel 29/29、Claude Code CLI 2.1.310 を実クライアントにした 4 シナリオ（`4.1` と `4.2` の両方で成功）。`4.1` はドラフト PR に一時置いただけで使わない。
- Claude Code 2.1.310 は MCP 2026-07-28（1 リクエスト＝1 POST、`Mcp-Session-Id` なし、`_meta.client_id` なし）。Unity 2 台のとき `set_active_instance` は「覚えられない」案内を返し、Claude Code は `unity_instance` を付けて呼び直す。
- Unity 側 zip：9.7.1 と内容が違う／新しい 220 ファイルは固定の新しい日時（10.3.0 ミラーで 2026-10-22 00:00:00、10.3.100 の `package.json` だけ 2026-10-23 00:00:00）、同じ内容の 524 ファイルは 1985-10-26 のまま。既存 3 版の zip はバイト同一。`tools/verify_listing.py` は OK。
